Monte Carlo BER over AWGN

Experiment 12. Simulate BPSK, QPSK, BFSK, 8-PSK, 16-QAM and 64-QAM, compare each against theory, and treat zero-error points as upper bounds.

Fixed conventions

Eb/N0 to noise
Es = 1 for every constellation. N0 = Es / (k · Eb/N0). Complex noise has variance N0; each real axis has variance σ² = N0/2.
Bits per symbol k
BPSK 1, BFSK 1, QPSK 2, 8-PSK 3, 16-QAM 4, 64-QAM 6.
Normalization
PSK on the unit circle. Square QAM scaled by √(2(L²−1)/3), L = √M. BFSK uses two orthogonal unit-energy dimensions, coherent detection.
Stopping rule
Each point stops at the error limit or the bit limit, whichever comes first. Gray mapping and minimum-distance detection throughout.
